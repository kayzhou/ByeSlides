# ByeSlides 帮助

在「编辑」里写 Markdown 源文，用 ⌘2 切到「阅读」查看排版，用 ⌘1 切回来继续写。打开一份空白文稿，就能复制下文的示例试写。

ByeSlides 一次打开一篇文稿。新建或打开其他文件时会切换当前文稿。若系统提示有未存储的修改，可以先保存，或取消后继续编辑。

## 快速上手

1. **打开或新建。** 直接启动默认打开当天的文稿，按本机日期命名为 `YYYY-MM-DD.md`，存放在 `~/Library/Application Support/ByeSlides/`。⌘N 新建空白文稿，默认用当天日期作为名称。⌘O 打开已有的 Markdown 或纯文本文件，也可以在 Finder 里用「打开方式 → ByeSlides」。
2. **打开文件夹。** 在文稿窗口选择「文件 → 打开文件夹…」，左侧会列出文件夹和 `.md`、`.markdown`、`.txt` 文件。点击箭头展开子文件夹，点文件名切换当前文稿。侧栏顶部的刷新按钮可更新列表，工具栏按钮或 ⌥⌘S 可收起侧栏。
3. **编辑。** ⌘S 存储。在列表项内按回车续写，后面连续的同级编号会顺延。在空列表项按回车结束列表。选中内容可用「格式」菜单加粗、加斜体或插入链接。底部显示全文字数，选中文本时也显示选区字数。
4. **阅读。** ⌘2 查看排版。两种模式切换时会尽量停留在同一段。正文宽度随窗口变化，两侧默认留白 32。可用 ⌘F 查找，以回车和 ⇧回车跳到下一个或上一个结果。查找与替换在编辑模式使用。
5. **输出。** 选择「文件 → 导出为 PDF…」或「文件 → 打印…」。两种操作使用阅读排版。在 Finder 中选中 Markdown 文件后按空格可以快速查看。

## 设置

从「ByeSlides → 设置…」打开，或按 ⌘,。

| 页面 | 可调整的内容 |
| --- | --- |
| 通用 | 直接启动时打开当天文稿、新建空白文稿或只启动应用。还可设定初始模式和两侧留白，在 Finder 中打开每日文稿目录。 |
| 编辑 | 默认 16 pt、1.5 倍行距。可调整字号和行距，开关光标所在行的浅蓝底、字数和列表续写。 |
| 阅读 | 默认 18 px、1.5 倍行距，正文使用霞鹜文楷。可调整字号、行距、两端对齐、中英文空隙、行末标点悬挂和远程图片策略。 |
| 键音 | 开关打字声，选清脆、柔和或低沉音色，调节音量并试听。 |
| 快捷键 | 查看常用文稿及编辑命令。 |

通用、编辑、阅读、键音各有自己的「恢复默认值」按钮。⌘0 只重置当前文稿窗口的显示缩放。

## 段落与标题

空一行开始新段。段内普通回车是软换行，阅读时仍属于同一段。要在段内强制换行，在行尾加两个空格或一个反斜杠。下例用可见的反斜杠。

```markdown
第一段的第一行
第一段的第二行

这一行结束后立即换行。\
这是同一段的下一行。
```

用一到六个 `#` 加空格写标题。标题后可以用空格隔开一串 `#` 作为可选的收尾。一级和二级标题也可以在标题文字下方加一行 `=` 或 `-`。

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题

另一种一级标题
==============

另一种二级标题
--------------
```

## 文字样式

| 写法 | 阅读效果 |
| --- | --- |
| `*斜体*` 或 `_斜体_` | *斜体* |
| `**粗体**` 或 `__粗体__` | **粗体** |
| `***粗斜体***` 或 `___粗斜体___` | ***粗斜体*** |
| `~~删除线~~` | ~~删除线~~ |
| ``` `行内代码` ``` | `行内代码` |

阅读视图用蓝色强调粗体文字。符号紧贴文字书写，中文两侧遇到文字或标点影响匹配时，可在标记外留空格。英文单词内部的下划线一般保留原样，如 `file_name`。

## 列表

无序列表用 `-`、`+` 或 `*` 加空格。有序列表用数字加 `.` 或 `)`，再加空格。写同一组列表时保持同一种标记。阅读视图根据有序列表第一项决定起始值，逐项递增。编辑视图保留源文中的实际数字。

```markdown
- 苹果
- 梨

3. 从第三项开始
4. 第四项

1) 也可以用右括号
2) 下一项
```

子列表和同一列表项的续段要缩进到父项正文开始的位置。比如 `- ` 后正文从第 3 列开始，通常缩进 2 个空格。`1. ` 后通常缩进 3 个空格。列表项之间加空行会使列表显示得更疏。

```markdown
1. 整理材料
   - 阅读原稿
   - 核对附件

   这段补充说明仍属于第一项。
2. 交付
```

任务列表在列表标记后写 `[ ]`、`[x]` 或 `[X]`，再加空格和文字。阅读模式的复选框只读，到编辑模式修改勾选状态。任务标记也可以接在有序列表标记后。

```markdown
- [ ] 待处理
- [x] 已完成
- [X] 也表示完成

1. [ ] 核对表格
2. [x] 存储文稿
```

- [ ] 待处理
- [x] 已完成

## 引用与分隔线

在行首写 `>`，然后加空格。引用可以包含段落、标题、列表和代码等块，也可以继续嵌套。

```markdown
> 第一段引用。
>
> 第二段引用。
>
> > 嵌套引用。
```

单独一行写至少三个相同的 `-`、`*` 或 `_`，可插空格，生成水平分隔线。用 `---` 分隔段落时，上方留空行，以免被当成上一行的二级标题下划线。

```markdown
一段文字

---

另一段文字

* * *
```

## 代码

行内代码用反引号包围，里面的星号、下划线等按原样显示。如果代码本身含有反引号，外层使用更多的反引号。

```markdown
执行 `swift test`。
`` 这里有一个 ` 反引号 ``
```

代码块用成对的至少三个反引号或波浪线作围栏，起始行可紧跟语言名。结束围栏使用相同符号，长度至少和开头一样。ByeSlides 保留代码格式和语言标记，阅读时按等宽文本显示。顶层也可用四个空格缩进写代码块，与前一段空一行。

````markdown
```swift
let greeting = "你好"
print(greeting)
```

~~~text
这里可以原样展示 ```。
~~~

    这也是一个代码块。
````

## 链接

行内链接用 `[文字](地址)`，地址后可加引号标题。有空格的本地文件名可以用 `%20` 编码，或用尖括号包住链接目标。

```markdown
[示例网站](https://example.com "网站标题")
[目录中的笔记](notes/读书.md)
[带空格的文件](<notes/第一章 阅读.md>)
[发送邮件](mailto:help@example.com)
```

引用式链接适合重用地址。可以写成完整引用 `[文字][标签]`、省略标签的 `[标签][]`，或者简写为 `[标签]`。对应的定义另起一行，通常统一放在文末。

```markdown
[语法规范][cm]、[cm][]、[cm] 都可以引用同一个地址。

[cm]: https://spec.commonmark.org/0.31.2/ "CommonMark"
```

尖括号可把完整网址或邮箱变成链接。ByeSlides 也能识别正文中的完整 HTTP(S) 地址和常见邮箱地址。省略协议的域名宜写成显式链接。

```markdown
<https://example.com>
<help@example.com>
https://example.com
```

用 `[文字](#标题)` 跳到本页标题。ByeSlides 将标题文字转为小写，去掉标点，把空白换成连字符。重复锚点依次加 `-1`、`-2`。例如 `## 第一天 计划` 可用 `[当天安排](#第一天-计划)` 跳转。

阅读模式中的网页由系统默认浏览器打开，邮件链接由系统处理。文稿目录及其子目录中的文本、PDF 和图片链接可交给对应的本机应用打开。

## 图片

图片和链接的写法相近，前面加 `!`。方括号是替代文字，地址后还可写可选标题。图片也支持引用式写法 `![替代文字][标签]`。

```markdown
![会议白板](assets/meeting.png "会议现场")
![远程图示](https://example.com/chart.png)
![图表][chart]

[chart]: assets/chart.png
```

先存储文稿，再把图片粘贴或拖进编辑区，ByeSlides 会插入引用。目录外的图片会复制到文稿旁的 `assets` 文件夹，已有的目录内图片会就地引用。移动或分享文稿时，一起移动对应的图片文件和目录。

远程图片默认按需载入，点击阅读页的「载入」才会请求图片。支持用 `<img src="assets/chart.png" alt="图表" width="320">` 设置显示宽度。Finder 快速查看只能读取选中的文件，文稿旁的图片需要在 ByeSlides 的阅读视图中查看。

## 表格

表头下一行写每列的分隔符。`:---` 左对齐、`:---:` 居中、`---:` 右对齐。用 `\|` 在单元格里显示竖线。单元格可用行内样式或链接，需要手动换行时可用 `<br>`。宽表可左右滚动。

```markdown
| 项目 | 进度 | 用时 |
| :--- | :---: | ---: |
| **写初稿** | 完成 | 30 分钟 |
| 校对 \| 补图 | 待办 | 15 分钟 |
```

| 项目 | 进度 | 用时 |
| :--- | :---: | ---: |
| **写初稿** | 完成 | 30 分钟 |
| 校对 \| 补图 | 待办 | 15 分钟 |

## 转义与字符实体

在 ASCII 标点前加反斜杠可将其按普通字符显示。行内代码和代码块已按原样展示文本，通常可以直接书写符号。字符实体也能生成特殊字符。

```markdown
\*这里包含实际的星号\*
\# 这一行是正文
[显示方括号](/) 可改写成 \[显示方括号\] 来显示整个标记。
5 &lt; 8 &amp; 9 &gt; 6
&copy;、&#169;、&#xA9;
```

## HTML

阅读视图可显示部分 HTML。常用的有 `<br>` 换行、`<kbd>` 键名、`<sub>` 下标、`<sup>` 上标、`<mark>` 高亮，以及 `<details>` 和 `<summary>` 折叠区。HTML 注释 `<!-- 备注 -->` 留在源文里，阅读时隐藏。脚本、样式、内嵌网页和交互式表单会被过滤。

```html
H<sub>2</sub>O，x<sup>2</sup>，<kbd>⌘S</kbd>，<mark>重点</mark>。

<details>
<summary>展开说明</summary>

这里可以写 **Markdown 正文**。标签和正文之间要留空行。

</details>

<!-- 此行只在编辑模式可见。 -->
```

## 语法兼容性

Markdown 有多种方言。ByeSlides 以 CommonMark 为基础，加入表格、任务列表、删除线、裸网址和本页标题锚点。应用内的这份指南覆盖当前支持的语法类别。几种常见扩展在 ByeSlides 中需要换写法。

| 写法 | 在 ByeSlides 中的处理 |
| --- | --- |
| 脚注 `[^1]` 和 `[^1]: 注释` | 可能被当作普通文本或链接引用。可以手写文末注释并用标题锚点跳转。 |
| 行内公式 `$x^2$`、公式块 `$$…$$` | 按正文显示。可用 Unicode 字符、HTML 上下标或插图。 |
| Mermaid、PlantUML 等图表围栏 | 显示代码内容。可先生成 PNG，再以图片插入。 |
| Obsidian 的 `[[笔记]]`、`![[附件]]`、`^块标记`、`%%注释%%` | 改用普通链接、相对路径的图片和本页标题锚点，或 HTML 注释。 |
| GitHub 提示框 `> [!NOTE]`、Obsidian Callout | 按普通引用显示，可在引用中手动写粗体小标题。 |
| Pandoc 等工具的 `: 定义`、`==高亮==`、`:smile:` | 可用普通段落、`<mark>高亮</mark>` 和系统 Emoji。定义列表也可用 HTML 的 `<dl>`、`<dt>`、`<dd>`。 |
| YAML 文首信息、`[TOC]`、`{#自定义-id}` | 按普通 Markdown 处理。目录可以用列表和标题锚点手写。 |

## 常见问题

- **编辑里的符号怎么还在？** 编辑模式显示 Markdown 源文，按 ⌘2 可看排版结果。
- **列表中间插入怎么避免重复编号？** 把光标放在要插入位置的前一项末尾，按回车。后续连续的同级编号会顺延，子列表各自保留编号。误操作按一次 ⌘Z 撤销。
- **本地图片为什么空白？** 先存储文稿，核对文件名和相对路径。图片要放在文稿所在目录或其子目录，移动 Markdown 时一起移动图片。
- **如何写出独立的下一段？** 在两段之间留一整行空行。只按一次回车会继续同一段。
- **怎样查看语法细节？** CommonMark 规格逐项解释标准语法。GFM 规格可用于查阅表格、任务列表和删除线的设计细节，具体兼容性以本帮助所列为准。 [CommonMark 规格](https://spec.commonmark.org/0.31.2/) · [GFM 规格](https://github.github.com/gfm/)
